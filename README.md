# Sistem Manajemen Kost

## Requirements
- PHP
- Composer
- Laravel
- MySQL

## Instalasi

1. Clone repository
2. Masuk ke folder project
3. Install dependency
4. Copy file .env
5. Atur database
6. Generate application key
7. Jalankan migration
8. Jalankan server

## Menjalankan Project

php artisan serve
